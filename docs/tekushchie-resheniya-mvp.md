# Текущие решения по MVP Food_for_week

Этот файл фиксирует уточнения, принятые после первичного опроса. Он не заменяет полное техническое задание, которое будет подготовлено отдельно.

## Рецепты и импорт

- Первый поддерживаемый источник — `food.ru`.
- Набор ссылок для разработки хранится в [testovye-retsepty-food-ru.md](./testovye-retsepty-food-ru.md).
- Импорт выполняется в фоне. Пока окно открыто, в нём показывается статус обработки; после успеха окно закрывается автоматически.
- Если пользователь закрыл окно, готовый рецепт появляется в конце каталога.
- Если фоновый импорт завершился ошибкой после закрытия окна, показывается всплывающее уведомление.
- В MVP разрешено минимально исправлять ингредиенты импортированного рецепта: название, количество и единицу измерения.
- Избранное, поиск и фильтры не входят в MVP.
- Настройка числа порций и пропорциональный пересчёт рецепта не входят в MVP.

## Ингредиенты и единицы

- Для ингредиента сохраняются исходное и нормализованное названия.
- Одинаковые ингредиенты автоматически объединяются по нормализованному названию.
- Граммы объединяются с килограммами, миллилитры — с литрами.
- Несовместимые или неизвестные меры не складываются: пример отображения — `300 г + 3 ложки`.
- Возможна небольшая проверенная таблица преобразований для частых ингредиентов, начиная с муки, сахара и воды.
- Значения `по вкусу`, `немного` и `для жарки` хранятся без выдуманного числового количества.
- Использование GPT для приблизительного преобразования единиц рассматривается только после MVP.

## Семидневный план и покупки

- План содержит фиксированный период из семи дней.
- Первый период начинается в день создания плана и включает следующие шесть дней.
- После окончания периода окно целиком сдвигается на следующие семь дней; ежедневного сдвига по одному дню нет.
- Список покупок автоматически сбрасывается при переходе на новый семидневный период.
- Список также можно сбросить отдельной кнопкой.

## Навигация

- Горизонтальный свайп переключает три основных раздела приложения.
- Свайп от самого левого края экрана не перехватывается, чтобы не конфликтовать с системным жестом iPhone.
- Нижнее меню всегда остаётся доступным как основной или резервный способ переключения разделов.
