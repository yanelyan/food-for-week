# Отложенные функции после MVP 2

Здесь перечислены функции, которые сознательно не входят в текущую локальную версию.

## Telegram и production

- Telegram-бот и одно напоминание о закупке в 09:00 по часовому поясу пользователя.
- Проверка интерфейса на iPhone внутри Telegram после готовности бота.
- Развёртывание на NAS, HTTPS, резервное копирование и production-мониторинг.

## Планирование

- Автоматическое составление меню по предпочтениям, стоимости, времени готовки и остаткам.
- Пищевые ограничения и аллергии.
- Настройка числа людей, порций и пропорциональный пересчёт ингредиентов.
- Одно действие для назначения блюда на несколько дней.
- Копирование недели и шаблоны меню.
- История завершённых недель.

## Рецепты

- Универсальный импорт с неподдерживаемых сайтов, в том числе с помощью модели.
- Ручное создание рецепта без ссылки.
- Полное редактирование названия, изображения, инструкции, времени, порций и калорийности.
- Удаление рецепта с безопасной обработкой уже запланированных блюд.
- Избранное и поиск по названию. Фильтр по приёму пищи уже входит в MVP 2.
- Загрузка собственных изображений.

## Ингредиенты и покупки

- Автоматическое приблизительное преобразование произвольных единиц с помощью GPT и явной пометкой неточности.
- Сортировка по отделам магазина.
- Ручное добавление товаров и изменение рассчитанного количества.
- Отправка списка через Telegram, копирование, печать и экспорт.
- Полноценный домашний склад, упаковки, сроки годности и предложения рецептов для использования остатков.

## Совместное использование

- Семьи, приглашения, роли и общий синхронизированный план.
- Одновременное редактирование списка несколькими пользователями.
