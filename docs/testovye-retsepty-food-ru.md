# Тестовые рецепты food.ru

Эти ссылки используются как начальный набор примеров для разработки и проверки импортера рецептов с `food.ru`.

1. [Паста-салат без зелени и оливок](https://food.ru/recipes/259841-pasta-salat-bez-zeleni-i-olivok)
2. [Картофельное пюре с печёным перцем к котлетам по-киевски](https://food.ru/recipes/274682-kartofelnoe-piure-s-pechenym-percem-k-kotletam-po-kievski)
3. [Сырные вафли с ветчиной](https://food.ru/recipes/259850-syrnye-vafli-s-vetchinoi)
4. [Паста с маскарпоне и томатами](https://food.ru/recipes/274838-pasta-s-maskarpone-i-tomatami)
5. [Салат из брокколи с изюмом](https://food.ru/recipes/274081-salat-iz-brokkoli-s-iziumom)
6. [Слойки-чизкейк с ягодами](https://food.ru/recipes/256527-sloiki-chizkeik-s-jagodami)
7. [Печенье сабле](https://food.ru/recipes/274618-pechene-sable)

## Что проверять на каждом примере

- распознавание названия рецепта;
- получение изображения или подстановка стандартной иллюстрации;
- извлечение исходного текста каждого ингредиента;
- разделение названия, количества и единицы измерения;
- сохранение неточных значений вроде `по вкусу` без подстановки фиктивного числа;
- нормализация названий и объединение одинаковых ингредиентов;
- корректное сообщение об ошибке при недоступности страницы или изменении её структуры.
